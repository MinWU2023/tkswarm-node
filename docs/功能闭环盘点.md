# 后台功能闭环盘点

对照基准：参考站 `http://127.0.0.1:8399`，当前后台 `http://127.0.0.1:8400`。  
盘点日期：2026-09-20。  
判定口径：

- **已闭环**：界面能点 → 后端有接口 → 有真实业务结果（或明确只写本系统）
- **半成品**：有入口，但只做了一半、依赖真机选择器未验、或容易让人误会成平台能力
- **未实现**：参考站有 / 计划要求，这里还没有
- **明确不做**：Studio / CapCut 官方发布、AdsPower 等、许可激活、**伪造** TikTok 私信同步（无 CK/接口失败时标记 unsupported，不写假消息）
- **有限实现**：API 模式 `dm_sync`：**CK HTTP IM 探测**；失败可 **Bit 打开 /messages 拦截 XHR 或 DOM 爬取**（`dmSyncBitFallback`）。失败 → unsupported，不写假收件箱。比特拉粉丝进 `chat_friends`；PHP `/api/translate`

盘点时本机比特浏览器 API（`127.0.0.1:54345`）为**未连接**；凡依赖比特的「已闭环」指代码链路已接通，正式发布/改资料仍需在已连接、已登录环境下再验一次。

---

## 一、总览结论

大业务主路径大部分已接通：登录、账号批量、代理、素材/UID、发布与群发向导入队、任务子项重试、客服本地会话、智能体试聊、设置备份与窗口模式。

仍未完全形成「平台侧」闭环的重点：

1. 比特自动发布、平台改资料、平台删视频：代码有回路，**选择器需真机实测**
2. API / WebSocket 群发：本系统会话；**API 模式私信同步**见消息设置 + `php artisan dm:sync`（**骨架探测**，失败为 unsupported，不伪造成功、不写假消息）
3. RBAC：登录用户已绑定 `role_id`，菜单按权限裁剪，敏感写接口会 403（见进度续 10）
4. 若干真机选择器仍依赖比特已连接环境；**刷新粉丝**现为拉列表任务（需 Node+比特）

## 三、半成品（有回路但不完整或易误会）

### 必须真机再验

- 自动发布：上传 → 点发布 → 成功判定依赖页面文案/选择器
- 平台修改资料：昵称 / 签名 / 头像
- 平台删除视频：依赖已同步视频列表与页面删除入口

### 能力是「本系统」，不是「TikTok 官方」

- 群发「API / WebSocket」：写入本地客服会话（WS 可实时推送），不是平台私信
- 客服「同步标记」、设置「私信同步」：不拉取 TikTok 收件箱
- AI 托管：无真实收信时，主要靠本系统消息或「模拟收信」触发
- CapCut 相关：仅本地标记，不能走 CapCut 发布

### 其它半成品

- 云端取代理：未配置云 API 时会**明确**回退本地池并提示来源（不再静默冒充云端）
- RBAC：权限/角色/登录管理员已接 `local_users.role_id`；菜单裁剪 + 敏感接口鉴权持续补全
- 设置「接口环境」：默认同源 Node；PHP 为显式选项
- 智能体自定义模型：依赖有效翻译/对话 API；规则引擎本身可跑
- 视频「预览」：本地仅有作品页链接与封面，非 mp4 直链播放
