> 对照基准（本地实测，2026-09-18）

## 1. 两边运行时差异速览

| 维度 | 8399（参考） | 8400（当前） |
|------|--------------|--------------|
| 产品形态 | 完整桌面业务端 + 登录页 | 本地管理后台 SPA，无登录 |
| 入口 | `/` → 登录；业务在 `/page/*` | `/` 直接进控制台 |
| 鉴权 | API 普遍 **401**（需登录态） | API 全开，无用户体系 |
| 技术栈观感 | Vue2 + Element UI；后端 Spring（有 `/actuator`） | 静态前端 + PHP API / Node 自动化，数据在 MySQL |
| 导航模块 | 账号管理 / 代理IP / AI机器人 / AI矩阵 / 客服聊天 / 系统设置 | 控制台 / 账号 / 代理 / 浏览器 / 任务 / 素材 / 模板 / 分组 / 设置 |
| 聊天通道 | `/websocket/chat` + 连接池 API | 仅 `/ws` 操作日志 |
| 发布能力 | Studio / CapCut / Bit 多通道任务 | Bit 环境 + **prepare 到人工确认** |
| 群发能力 | API / WS 群发 + UID 好友组 | message 任务仅 prepare，不发送 |
| AI | AI 机器人整页 + 翻译配额 + Token | 无 |
| 实测数据（8400） | — | 账号 8、代理 100、素材有、任务 1（publish/paused）、模板空、比特浏览器 offline |

### 1.1 页面对照

| 8399 页面 | 8400 对应 | 差距判定 |
|-----------|-----------|----------|
| `/page/index` 登录 | 无 | 缺用户登录/注册/验证码 |
| `/page/account` 账号管理 | `/` → accounts | 有 CRUD/导入/登录辅助；缺扫码、CK/CapCut、客服批量上下线、AI 监控、多格式导入等 |
| `/page/proxy` 代理IP | proxies | 有 CRUD/导入/TCP 检测；缺云端取 IP、轮转、地理级联 |
| `/page/agent` AI机器人 | **无页面** | 整模块缺失 |
| `/page/publish` AI矩阵 | tasks + materials | 有任务/素材骨架；缺 Wizard、多通道自动发布、群发、UID |
| `/page/chat` 客服聊天 | **无页面** | 整模块缺失（仅有 message-prepare） |
| `/page/settings` 系统设置 | settings | 有浏览器/任务参数；缺激活码、翻译、消息同步、无头功能位、多国时钟 |
| （无独立页） | browser 环境页 | 8400 多出独立「浏览器环境」管理（参考侧嵌在账号/设置） |

## 2. 当前已具备（不必重复建设）

1. 账号 / 代理 / 分组 CRUD，批量导入（账号格式仅 `账号----密码----2FA`）
2. 账号密码 / 2FA AES-256-GCM 加密存储
3. 比特浏览器：健康检查、环境创建/打开/关闭/删除、绑定解绑、批量创建
4. Cookie 登录检测、登录辅助填表（默认不自动提交）
5. 资料同步 / 视频列表同步任务（可全自动）
6. 素材库上传、预览、sha256 去重
7. 任务队列：排队、并发、暂停、取消、重试、事件、runs、方案 prepare/confirm（confirm 不触发自动发布）
8. Dashboard 统计 + `/ws` 操作日志
9. 设置持久化（部分键尚未被执行器消费）

## 3. 缺口总表（按优先级）

优先级说明：

- **P0**：主业务闭环阻塞（无此则无法对齐官网「发布 + 聚合聊天」）
- **P1**：显著提升矩阵运营效率
- **P2**：体验 / 商业化 / 生产化
- **P3**：参考侧也标注「开发中」或隐藏，可后置

### P0 — 核心闭环

| ID | 缺口 | 参考侧证据 | 当前侧现状 | 建议交付物 |
|----|------|------------|------------|------------|
| P0-01 | 视频自动发布执行器 | `page_publish` 三通道 + `/api/task/video/*` | 仅 `preparePublish`，不点发布 | Bit/Studio/CapCut 执行器；confirm 后可自动跑 |

## 5. 分期实施计划（建议）

### Phase A — 发布真正可用（对齐官网「批量矩阵发布」）

1. 扩展任务 payload：通道、策略、定时、文案/@、省流  
2. 实现 Bit 通道自动发布（保留人工确认开关）  
3. 子任务表 + 失败重发 + 详情 UI  
4. 素材文件夹与 random/deduplicate  
5. （可选）Studio / CapCut 通道适配  

**退出标准：** 选账号 + 素材 → 一键任务 → 视频出现在账号作品列表（合法自有账号环境）。

### Phase B — 聚合聊天可用（对齐官网「聚合聊天」）

1. 好友 / 消息数据模型  
2. `/websocket/chat` 或等价推送通道  
3. 聊天三栏 UI + 筛选器  
4. 发送队列、已读、基础文本收发  
5. 账号批量登录/退出客服  

**退出标准：** 多账号同时在线，同一页收发私信。

### Phase C — 群发 + UID

1. UID 组管理  
2. 群发 Wizard（API 优先，再 WS）  
3. 发送对象策略 + 间隔重试  
4. 话术分类接入聊天与群发  

### Phase D — AI 与翻译

1. 翻译适配器 + 配额设置（可先无商业激活）  
2. AI 机器人 CRUD + 测试聊天  
3. 终止条件与资源轮询  
4. 聊天 AI 托管绑定  

### Phase E — 账号运营加强

1. 扫码登录、多格式导入、CK/CapCut 门禁  
2. 批量改资料 / 删视频 / 校准 IP  
3. 账号监控（AI 更新）与统计面板  
4. 云代理 fetch + 真实检测  

### Phase F — 生产化

1. 可选本地鉴权  
2. 敏感字段全加密、备份恢复  
3. 多浏览器 Provider、无头功能位  
4. 安装器 / 自动升级 / 进程隔离（按需）  

### Phase G — 设置落地与体验对齐（已完成）

1. `taskMaxRetries` / 无头开关接入执行器；任务 CSV 换行修复；批量重试覆盖 publish/message  
2. 消息设置卡 + 提示音 `/api/audio/playMessage` + WS 新消息播放  
3. 账号导出对话框（范围/格式/字段）+ 诊断按钮 + 批量登录客服  
4. 设置页浏览器工具；代理编辑/复制；编辑代理时密码可保留  

### Phase H — 页面视觉对齐（已完成）

1. 客服聊天四栏（账号 | 筛选侧栏 | 好友 | 会话）  
2. AI 矩阵顶栏 + 状态 Tag + 任务详情弹窗  
3. 代理页批量条 + 扩展表格列 + 现代侧栏  
4. 聊天筛选计数扩展；方案确认文案修正；消息同步间隔驱动刷新  

### Phase I — Agent / 素材 / 壳层收尾（已完成）

1. 修复 batchImportProxies、taskDetailModal 关闭与页脚  
2. 页面标题条；Agent 批量删除、头像、config-section、终止匹配方式  
3. 素材库卡片网格 + 预览 + 字段映射修复

### Phase J — 素材文件夹与发布向导对齐（已完成）

3. 发布 Wizard 第 3 步：素材库 / 文件夹路径 + 去重/随机分配  
4. 发布确认成功且开启「发后删除」时，删除本地视频并标记素材缺失  

### Phase K — Element Plus × Tailwind 全站美化（已完成）

1. 新增 `theme-ep.css` 作为最终样式层，统一 EP 主色 / 标签 / 表单焦点环

### 7.3 按参考站页面的缺口

**账号（`/page/account`）**  
已有单账号登录辅助、检测、改资料、删视频、转移分组、导出。缺：按分组批量分配代理、按分组批量登录、批量删除封号账号、批量提取指纹、复制 CK、行内「添加自定义 SOCKS5」。

**代理（`/page/proxy`）**  
已有添加、批量导入、检测、删除、SOCKS、云端获取。缺：高级删除（按状态/国家/失败次数）、列表内直接改 IP、复制代理串。

**AI 矩阵（`/page/publish`）**  
已有创建发布/群发、素材、UID 导入。缺：任务子项列表（每条视频/每条私信的成功失败）、失败批量重发、子项改文案、UID 去重与未使用导出、发后删除在「需人工」时的明确结果。比特发布必须从排队跑到页面点击发布或明确失败原因，不能停在 prepare 空转。

**客服（`/page/chat`）**  
本地会话、话术、已读、连接状态已有。缺：标签、置顶、拉黑、搜索用户、刷新粉丝数、按状态筛选好友、表情/图片、全局模式。真实 TikTok 私信同步不伪造成功：没有官方会话接口时，界面只展示「本地队列 + 比特环境手工发送」，并写清未同步。

**AI 机器人（`/page/agent`）**  
主体已有。补：保存后列表与试聊用的是同一份配置；开场白、轮询、匹配规则在试聊里真的生效。

**系统设置（`/page/settings`）**  
已有浏览器地址、翻译、消息、任务、备份。缺：顶栏语言只保留能切换的中文（英文整站未翻译完之前不放语言菜单）、多国时钟若保留就必须可增删并显示时间、比特「测试连接 / 删除环境」走已有浏览器 API。个人中心：改密码、退出（退出已有则核对可点）。

### 7.4 实施顺序

1. **清虚设**：隐藏或移除 7.2 里所有只 toast / disabled 的入口，避免用户点到死按钮。  
2. **账号批量**：分组分配代理、分组登录、批量删封号、复制 CK、提取指纹。  
3. **矩阵子任务**：发布/群发详情里每条子项可查看、失败可重发。  
4. **比特发布闭环**：向导创建 → 队列执行 → 打开环境 → 上传并点击发布或返回明确错误；发后删除只在真正发布成功时删文件。  
5. **客服交互**：标签、置顶、图片消息、搜索；全局模式做成跨账号收件箱，做不到的入口不留。  
6. **代理收尾**：高级删除、复制代理、行内编辑。  
7. **比特群发**：在环境里发送私信；做不到之前不显示该通道。  
8. **设置与个人中心**：测试连接、时钟、改密码；不实现商业激活。

Studio、CapCut、AdsPower 不在本轮冒充可用。真实 TikTok 全量私信同步单列，不写入假消息。

## 7. 非目标 / 约束
